# SoundWave Music Web App

Музыкальный веб-сервис с возможностью прослушивания и скачивания треков.

<img width="1920" height="999" alt="Screen1" src="https://github.com/user-attachments/assets/60d827f5-282a-4f76-b034-afafadcf3bcb" />

## Технологии

* ASP.NET Core Web API
* Entity Framework Core
* React
* SQL Server

## Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/USERNAME/soundwave-music-app.git
```

### 2. Открыть решение в Visual Studio

### 3. Создать базу данных

В Package Manager Console выполнить:

```
Update-Database
```

Это создаст базу **SoundWave** и все таблицы.

### 4. Запустить проект

```
npm install
npm start
```

или запустить через Visual Studio.
